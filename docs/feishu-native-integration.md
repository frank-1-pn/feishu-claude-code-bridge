## 恢复与隐私

主 worker 是唯一集成人，依次连接原生路由、卡片、附件、回调队列和云文档队列。动作校验当前 bot/profile、chat、sender、thread、原任务及实际卡片消息；不接受回调指定其他负责人或发送目标。外部消息中的内部状态字段会被清理。

原生发送在网络请求前持久化不可变正文、引用目标和幂等键；结果不确定时不换端点或改发另一条消息。消息去重保守使用 55 分钟界限；任务创建保守使用 240 秒界限，超时保留记录并停止自动新建。旧附件保持原发送端点和 UUID，避免升级导致重复。云文档的非幂等创建结果未知时也不盲目重建。

音频确认及本地提示采用原 inbox 状态机：送达 checkpoint 与任务状态均落盘后才标为完成；等待输入重启后不执行模型；确认后沿用同一原消息，并去重确认操作。任务和云文档使用独立循环，不将权限失败当成 WebSocket 断线。

日志和状态报告只包含计数、错误码和状态；CLI 原始 stderr 不写入日志。Bot key、真实绑定、回调、消息正文、文档/任务标识及验证 proof 全部保留在本机私有目录。
